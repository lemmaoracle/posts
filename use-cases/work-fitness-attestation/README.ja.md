# ユースケース: 就業要件照合 ── 健康診断・研修

## テーゼ

**スタッフを、就業要件と照合する。結果だけを受け取り、健康情報は渡さない。**

就業要件の確認は「検便結果や健診情報まで集めれば要配慮個人情報の保管を抱える、集めなければ要件を確かめられない」というジレンマを抱えています。Lemma は照合の**結果だけ**を ZK 証明として渡し、健診結果・受講履歴は出しません。受け取った側（配属・現場・監査）は中身を見ずに「就業要件を満たすか」を独立に検証でき、失効（有効期限切れ）も追えるため「確認時は有効だったが今は期限切れ」も検知できます。

有資格者の配置照合が「この現場に配置してよいか」を扱うのに対し、こちらは「その仕事に就かせてよいか」を扱います。照合する対象が資格ではなく健康と研修である点が、この UC の中心です。
