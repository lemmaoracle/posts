# ユースケース: 機微を渡さない現場連携

## テーゼ

**印は流通する。理由は流通しない。**

要注意顧客への対応、与信フラグ、二名体制の発動——現場が動くために必要なのは「該当する」という事実（印）だけで、その理由や根拠まではいりません。理由を現場に開示すれば漏洩や属人的判断を招き、隠せばフラグの正当性を後から示せない。Lemma は、現場には「印（対応区分）」だけを証明として流通させ、根拠データは管理部門（権限者）に留めたまま選択的開示で参照する構造を提供します。誰が・いつ・どの根拠で印を付けたかは改ざんなく来歴（Pillar 01）として残り、監査・苦情・本人開示請求に対して発行根拠を後から限定的に証明できます。既存の顧客管理・ブラックリスト共有の仕組みは置き換えず、証明のレイヤーだけを足します。
